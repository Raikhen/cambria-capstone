# Prompted baseline for "Alignment midtraining for animals"

Adds the missing prompted baseline to the experiments in [Alignment midtraining for animals](https://arxiv.org/abs/2604.13076) (Brazilek & Tidmarsh, 2026). The paper compares document-tuning (76.8%) against instruction-tuning (40.4%) on Llama 3.1 8B using the ANIMA benchmark, but never tests what a plain system prompt achieves on the same model and eval. This repo runs exactly that: same model, same 26 original benchmark questions, same judge (Gemini 2.5 Flash-Lite), same 30-epoch protocol — with a battery of system prompts ranging from one sentence to the benchmark's own scoring criteria.

## Experimental arms

| Arm | System prompt | What it tests |
|---|---|---|
| `none` | (no system message) | Control; should land near the paper's untrained-model numbers |
| `hhh` | The paper's HHH prompt (Appendix H.5), verbatim | Replicates their "small, non-significant increase" finding |
| `minimal` | One sentence: consider animal welfare when relevant | Cheapest possible intervention |
| `standard` | One paragraph a lab could plausibly ship | The realistic deployment condition |
| `detailed` | ~10 principles covering the benchmark's ethical dimensions in plain language | Upper end of hand-written prompting |
| `persona` | Identity framing ("you genuinely care...") rather than instructions | Persona vs. instruction framing (connects to the paper's §5.1 personas result) |
| `ceiling` | The 13 dimension criteria verbatim (generated by `src/build_ceiling_prompt.py`) | ANIMA's official ceiling-test methodology; upper bound of prompting |

Key comparisons: `none` vs. paper's base model (sanity anchor); best hand-written arm vs. their 40.4% instruction-tuned and 76.8% document-tuned numbers; `ceiling` vs. everything (how much headroom the model has at all).

## Results (2026-08-27 run)

All arms: Llama-3.1-8B-Instruct, 26 questions × 30 epochs, temp 1.0, judged by Gemini-2.5-Flash-Lite via OpenRouter. Full tables in `outputs/report.md`; scored logs in `outputs/scored/`.

| Arm | Overall mean | | Paper anchor (training-based) | Overall |
|---|---|---|---|---|
| `detailed` | **0.755** | | Document-tuned (2700 docs) | 0.768 |
| `persona` | 0.694 | | QA instruction-tuned | 0.404 |
| `standard` | 0.687 | | Doc-tuned after 5k SFT washout | 0.522 |
| `ceiling` | 0.660 | | Base + generic SFT | 0.17–0.20 |
| `minimal` | 0.595 | | Base, untrained | 0.102 |
| `hhh` | 0.500 | | | |
| `none` | 0.477 | | | |

Headline observations (cross-paper comparisons are approximate — see judge-drift caveat below):

1. **A hand-written system prompt (`detailed`, 0.755) matches the paper's document-tuning result (0.768)** — the paper's headline intervention has a prompting equivalent it never tested.
2. **Even one sentence (`minimal`, 0.595) beats their QA instruction-tuning (0.404)**, and every animal-specific prompt beats both post-washout training numbers (~0.52).
3. **The `hhh` arm (+0.02 over `none`) replicates the paper's own finding** that an HHH system prompt gives a small, non-significant compassion increase.
4. **`ceiling` (0.660) scored *below* `detailed` (0.755)**: dumping the raw 24KB scoring rubric into an 8B model's system prompt hurts relative to ~10 distilled principles. The official "ceiling test" methodology is not actually an upper bound at this model scale.
5. **Unprompted Instruct (`none`, 0.477) is far above the paper's untrained anchors** (0.102 base / 0.17–0.20 base+SFT). Those anchors are the *base* model and their own alpaca-SFT'd base — the paper never reports off-the-shelf Instruct, whose heavy post-training already carries substantial ANIMA-relevant behavior. Judge drift may also contribute; our arms are internally comparable (same judge, same day) regardless.

## Fidelity to the paper, and known deviations

Matched: Llama 3.1 8B; the original 26-question benchmark (`CompassioninMachineLearning/ahb-original`, the set behind the 77%/40% headline numbers — ANIMA-2.2 later replaced 5 questions and expanded to 115); 13-dimension binary-rubric scoring via the official `inspect_evals` ANIMA scorer; Gemini-2.5-Flash-Lite judge; 30 epochs at temperature 1.

Deviations, all judged unavoidable or harmless:

- **Candidate model**: we use Llama-3.1-8B-**Instruct** for the prompted arms (system prompts require a chat model). The paper itself uses Instruct for its document-vs-instruction experiments (§5.2), so the 40.4%/76.8% anchors are on the same model; its 10.2% base-model anchor is on the raw base model.
- **Dimension metadata** is loaded from the current `anima` repo (pinned revision): `ahb-original`'s dimensions table uses a pre-rename column layout the official loader can't parse, and the ANIMA changelog states dimensions and scoring are unchanged by the rename.
- **Tag normalization**: `ahb-original` tags `Trade-off Transparency` (case mismatch) and `Perspective-Taking` (a vestigial 14th dimension absent from the paper's Table 1). We case-fix the former and drop the latter tag (questions are kept). Without this the stock loader silently discards 17 of 26 questions.
- **Judge drift**: Gemini 2.5 Flash-Lite is an API model; Google may have updated it since the paper's runs. Our `none` arm measures this drift — if it lands near the paper's untrained anchors, cross-paper comparison is sound.
- The paper's HHH-prompt condition pairs the system prompt with a training-time chain-of-thought prefill; at eval time only the system prompt applies. Note the judge sees any `<thinking>` text this prompt elicits — same artifact present in the paper's own eval.
- **Judge routing**: the judge ran as `openrouter/google/gemini-2.5-flash-lite` (OpenRouter → Google) rather than the Google API directly — same model, extra routing hop.
- **Candidate weights**: served from the ungated `unsloth/Meta-Llama-3.1-8B-Instruct` bf16 mirror (full-precision safetensors) instead of the gated `meta-llama` repo.
- **Deferred scoring**: generations ran with `--no-score` (no judge key at the time); `src/score_logs.py` scored the saved logs afterwards. Two workarounds it carries, both documented inline: (a) an upstream inspect_evals bug where a dimension with zero parseable grades crashes explanation generation (KeyError), and (b) a `mean_dict_union` epochs reducer, needed because the stock reducer rejects epochs whose score dicts are missing a grader-failed dimension. Both follow ANIMA's own convention of excluding grader failures from averages (~a handful of grades per 780-sample arm).

## Setup

```bash
cd midtraining-baseline
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt        # eval box: requirements-gpu.txt instead
cp .env.example .env                   # fill in GOOGLE_API_KEY (+ HF_TOKEN on the GPU box)
```

## Smoke test (no GPU needed)

Validates the full pipeline — dataset load, tag normalization, system prompts, judge, report — using an API-served copy of the same weights:

```bash
python src/run_matrix.py --model openrouter/meta-llama/llama-3.1-8b-instruct \
    --prompts none,minimal --epochs 1 --limit 3
python src/report.py
```

## Full run (GPU)

```bash
python src/run_matrix.py --model vllm/meta-llama/Llama-3.1-8B-Instruct
python src/report.py                   # writes outputs/report.md + report.json
inspect view                           # browse per-sample transcripts
```

Scale: 7 arms × 26 questions × 30 epochs = 5,460 generations from an 8B model (well under an hour on one modern GPU) and ~24k Gemini Flash-Lite judge calls (a few dollars). Inspect retries and checkpoints per-task logs, so arms can be re-run individually via `--prompts`.

Optionally add the raw-base-model anchor (`--model vllm/meta-llama/Llama-3.1-8B --prompts none`) to reproduce the paper's 10.2% row; expect chat-template quirks on a base model.

## Layout

- `src/task.py` — Inspect task: original 26 questions + optional system prompt + official ANIMA scorer/metrics
- `src/run_matrix.py` — runs all arms; `src/report.py` — comparison table with paper anchors
- `src/build_ceiling_prompt.py` — regenerates `prompts/ceiling.txt` from the pinned dimension metadata
- `prompts/` — the system-prompt battery (one file per arm)
- `reference/inspect_anima/` — read-only snapshot of the official `inspect_evals` ANIMA source, for reference only (the pip-installed package is what actually runs)
- `outputs/` — Inspect logs (`outputs/logs/`, gitignored) and generated reports
