## What the page shows

A steering-vector sweep on Llama-3.1-8B: the same prompts answered at 17 steering coefficients (α from −32 to +32; positive = steered toward animal compassion, negative = against). Two kinds of items:

- 48 booking cells (`outputs/steer_results.jsonl` + scenario definitions in `data/eval_mc_scenarios.json`): 12 scenarios × 4 prompt variants; replies are ≤8 tokens (an option letter); each is scored safe/harmful programmatically. The exact prompt differs per variant — reconstruct it with the `scenario_variants`/`render_options` logic already in the builder (kept in sync with `src/steer.py`).
- 16 neutral free-generation prompts (`outputs/steer_generations.jsonl`): full ~300-token responses; the interesting phenomenon is animal-related content leaking in as α rises (a keyword regex marks candidate leaks — it's a lexical flag, surface it as such, not as a verdict).

## Hard requirements (from Dylan, verbatim intent)

1. Responses **side by side** across steering coefficients — full transcripts, nothing truncated, this is a *reading* tool first.
2. **Filter which coefficients are shown** (all 17 is too many at once; a sensible default subset with instant toggling).
3. **Local HTML only** — a single self-contained file opened via `file://`. No artifact publishing, no hosting, no external requests except Google Fonts.
4. Show the **exact verbatim prompt** the model saw for the selected item.
